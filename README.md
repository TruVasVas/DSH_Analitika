# Аналитика

Демонстрационный дашборд продаж и рекламы. Все данные вымышленные; внешние API и ключи не требуются.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

`npm run build` — production-сборка; `npm run preview` — её просмотр; `npm test` — проверка расчётов.

## Данные и расчёты

Исходные данные — `src/data.js`. Период: 19–25 октября 2026. Фильтры применяются кнопкой «Обновить».

- Выручка = количество × цена. Дневные данные суммируются в данные по артикулам.
- Маржа = выручка − себестоимость − комиссия (15%) − логистика (80 ₽/шт.) − прочие расходы (5%) − реклама.
- Маржинальность = маржа / выручка. Все заказы считаются выкупленными; налоги не включены.
- ДРР = расходы на рекламу / рекламная выручка; CTR = клики / показы; CR = рекламные заказы / клики.
- План и рекламные расходы распределены равномерно по дням; рекламные заказы, клики и показы округляются до целых.
- Сравнение с предыдущим периодом использует отдельные демонстрационные объёмы [108, 82, 65, 38] шт.; для коротких периодов применяется пропорция дней.
- Дни запаса = остаток / средние продажи в день. В Коледино 50 единиц при 117 продажах за 7 дней: 2,99 дня, в предупреждении округлено до 3.
- План выполнен, если выполнены показатели и в штуках, и в рублях.

Данные хранятся локально, без сервера и персональных данных. Страница адаптирована для мобильных устройств, широкие таблицы прокручиваются внутри своих блоков.
